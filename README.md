# Saints HUD

Broadcast tools for St. Clair Saints esports.

- [`squish-hud/`](squish-hud/): the control room app. A local Node server with a dashboard, OBS overlays, and live data from Rocket League (official Stats API), League of Legends (Live Client Data API) or any OCR tracker. See its [README](squish-hud/README.md) to run it.
- `squish-overlays.html`, `squish-control-room.html`: the original single-page design prototypes.
