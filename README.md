# Saints HUD

Broadcast tools for St. Clair Saints esports.

- [`app/`](app/): the Saints HUD desktop app: control room, OBS overlays, live Rocket League and League of Legends data, and screen OCR for other games. See its [README](app/README.md).
- `saints-overlays.html`, `saints-control-room.html`: the original single-page design prototypes.
