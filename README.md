# Saints HUD

Broadcast tools for St. Clair Saints esports.

- [`squish-hud/`](squish-hud/): the Saints HUD desktop app: control room, OBS overlays, live Rocket League and League of Legends data, and screen OCR for other games. See its [README](squish-hud/README.md).
- `squish-overlays.html`, `squish-control-room.html`: the original single-page design prototypes.
